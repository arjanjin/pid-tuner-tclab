- ลูกศรซ้าย/ขวา หรือปัดหน้าจอ เพื่อเปลี่ยนสไลด์
- `F` เต็มจอ, `Esc` ภาพรวมทุกสไลด์
- เติม `?print-pdf` ท้าย URL แล้วสั่ง Print → Save as PDF ใน Chrome (เปิด Background graphics) เพื่อสร้าง PDF ใหม่
